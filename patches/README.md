# AG Grid 36.2.0: завершение PageUp / PageDown

В таблице с автоматической высотой строк AG Grid повторно переводит фокус через
50 мс после PageUp / PageDown. В исходной версии этот callback может отменить
более поздний Home / End, другой переход по ячейкам или фокус через API.

Патч сохраняет исходное перемещение и повторное измерение высот, но выполняет
отложенное продолжение только пока таблица существует и фокус AG Grid не был
заново установлен. Изменены оба используемых входа пакета: ESM и CommonJS.
Версия библиотеки не меняется; собственный алгоритм навигации не добавляется.

Патч применяется через `patchedDependencies` в `pnpm-workspace.yaml` и lockfile.
Docker копирует каталог до установки зависимостей. При обновлении AG Grid
проверить, устранён ли дефект в новой версии, и убрать патч, если он больше не
нужен. Не переносить его на другую версию без повторной проверки.

Регрессии: `e2e/tests/grid-keyboard-overlap.spec.ts` (быстрые сочетания в Chromium
и WebKit), обычная навигация и поля назначения — `line-program-ag-grid.spec.ts`.
