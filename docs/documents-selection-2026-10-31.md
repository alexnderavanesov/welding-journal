# Выбор и фокус в документах — 31 октября 2026

Исправлен общий AG Grid реестров документов. До правки проверки обоих типов реестра воспроизводили отсутствие диапазона при перетягивании мышью по галочкам. Обработчик Shift+Пробел также использовал опорную строку вместо выделенной области ячеек.

Теперь Shift+Пробел переключает документы всего диапазона, включая столбец галочек, несколько областей с Cmd/Ctrl и незагруженные строки раскрытых групп. Выбор вне диапазона сохраняется, пересечения не удваивают документы. Запросы ограничены порциями по 500 строк и одной ревизией; смена диапазона, отбора, выбора или закрытие реестра отменяет применение старого ответа. Ошибка поздней порции не оставляет частично выбранный набор. API и серверные ограничения доступа не менялись.

Обычный пробел переключает одну строку; Shift+клик сохраняет прежний выбор от опорной строки. Клик по галочке убирает старый диапазон. Ранний фокус без прокрутки сохраняет первый клик по частично видимой строке; расширенная область нажатия галочек группы и шапки активирует их один раз. Enter/F2 раскрывает группу без второй области и сохраняет столбец для дальнейшей навигации, не сбрасывая отмеченные документы. Руководство обновлено.
