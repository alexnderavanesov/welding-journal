## Правила

- Корень_1 → Клеймо_1; Заполнение_1 → Клеймо_2; соответствующие фактические поля → Клеймо_1 - факт / Клеймо_2 - факт. Остальные восемь полей удалить. Сохраняемые значения не объединять и не подменять. Внутренние ключи/колонки этих четырёх полей можно сохранить: это прямое переименование, без слоя совместимости.
- С/У: два равноправных официальных и два фактических клейма без слоёв. Официальное и фактическое могут различаться. Т: только первая пара, вторые поля запрещены. По уточнению пользователя на production нет Т-стыков.
- Допуски официальных клейм, совместное покрытие способов, материалы, размеры, даты, архив/отстранения и исключение для несвязанных исправлений сохраняются. Послойный контроль — отдельный процесс и не удаляется.
- Статистика фактических сварщиков, включая прошлые периоды: одно уникальное клеймо = 100%, два разных = 50/50, повтор одного = 100%, без факта нет распределения по сварщикам. Общий объём и процентная база программы контроля не делятся по этому правилу.
- Каждая используемая пара проверяется независимо: одно поле заполнено → напоминание дозаполнить второе; оба заполнены или оба пусты → нет предупреждения о неполной паре. Для Т проверяется только первая. Напоминание не запрещает сохранение; проверки даты и допуска независимы.
- Кнопка «Заполнить фактические»: официальное копируется только в пустое соответствующее фактическое; введённый факт не перезаписывается.
- Импорт только с новыми названиями, без поддержки старых. Сохраняются проверка итоговой записи, различие отсутствующей колонки и очистки, все ошибки строки, атомарность и версии.
- В шаблонах сохраняемые привязки переименовать; удаляемые очистить/удалить без догадок и сложной совместимости. Пользователь поправит оформление вручную. Проверить конструктор, маркеры, ФИО, участников и скачивание.
