# Конструктор шаблонов: историческая дорожная карта

**Последнее уточнение пользователя 02.11.2026:** после решения «развитие не актуально» пользователь попросил сохранить только нереализованный остаток в отдельном [списке задач с неопределённой нужностью](tasks-to-consider.md), кандидат № 2. Вести его при дальнейших обсуждениях и передавать в следующие чаты; в согласованную очередь реализации не включать. Существующие возможности сохраняются.

Ниже сохранено описание первого этапа и прежних идей. Часть возможностей позднее реализована; этот список не является описанием текущих ограничений или очередью работ.

## Принцип первого этапа (история)

- Исходный Excel-файл отвечает за постоянное оформление.
- Конструктор хранит отдельную схему привязки системных данных к ячейкам.
- Исходный файл не изменяется конструктором.
- Для одного типа документа пока используется один активный шаблон и один выбранный лист.
- Табличные документы используют одну образцовую строку.
- Сводные документы могут собирать выбранные значения в одной ячейке.

## Исторический список идей

1. Несколько шаблонов или версий для одного типа документа.
2. Архив и восстановление старых настроек конструктора.
3. Повторяемый блок из нескольких строк вместо одной образцовой строки.
4. Несколько повторяемых областей на одном листе.
5. Одновременное заполнение нескольких листов книги.
6. Условные правила вида «если поле заполнено, иначе...».
7. Формулы и вычисляемые выражения внутри конструктора.
8. Дополнительные агрегаты: минимум, максимум, среднее и группировки.
9. Редактирование оформления ячейки прямо на сайте.
10. Точное отображение картинок и сложного Excel-оформления в браузерном предпросмотре.
11. Полный предпросмотр готового документа до скачивания.
12. Инструмент переноса старых шаблонов с ручными маркерами в визуальный конструктор, если он понадобится.

## Ограничение первого этапа

При развитии конструктора нельзя менять смысл уже сохраненной привязки без явной миграции конфигурации. Новые возможности должны быть совместимы с простым режимом: одна книга, один лист, одна повторяемая строка и сводные ячейки над ней.
