## Последние бизнес-решения, которые важно сохранить

- НК до ТО: «На выбранных стыках» — режим нового проекта; новая независимая цепочка выключена. Второй режим — «На всех стыках с ПСТО». R/W и неофициальные тёзки одной физической цепочки наследуют отметку; каждая сторона Y независима. Переключение старого включённого процесса сохраняет требование существующим стыкам с ПСТО, даже без документов; дальнейшие явные отключения не перезаписывать.
- Настройка «Разрешать основной НК до завершения предыдущих этапов» удалена: разрешающий режим постоянный. Сохраняются предупреждения, СП-06 для соответствующей фактической истории, хронология, блокировка по предварительному браку и прежний отбор готовых позиций в массовом выборе. Само ожидание не равно выполнению контроля.
- Статусы «ожидает заявку до ТО» / «ожидает НК до ТО» используются только при применимой потребности предварительного комплекта. Приоритеты ошибок, брака и неактуальности сохраняются.
- Отключение запрещает текущий «Ремонт»/«Вырез» именно до ТО; основной брак не запрещает отключение. После исправления предварительного брака можно отключить с точным подтверждением. Удаляются только подтверждённые предварительные позиции, чужие позиции общих документов и остальные этапы сохраняются. Снятие ПСТО сохраняет отметку/историю, но прекращает новую потребность до ТО.
- Быстрое заполнение создаёт только отсутствующие заявки и годные заключения назначенных методов. Любые новые даты/имена доступны для правки, существующие факты не заменяются. Неизвестный старый результат требует ручной проверки. Карточка сохраняет отметку и заполнение одной операцией; ЛНК — только явно выбранный подходящий состав. Столбцы автоматически не скрываются.
- Участники: сварщики — **только по шести официальным клеймам**, не фактическим; из заключений — **только исполнители «Провёл контроль» и «Оператор-термист»**. Исторические снимки удостоверений сохраняют различия; чужие документы, заявки и проверяющие не включаются. Список относится к выбранным стыкам, повторный экспорт получает свежие источники с сохранением правил исторических заключений.
- Новые поля справочников для списка участников **не добавлять**: пользователь заполнит недостающие реквизиты вручную и при необходимости поручит их отдельно. Простой конструктор предпочтителен расширению без выбранной задачи.
