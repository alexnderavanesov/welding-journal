## Масштаб и ограничения

Обзор по-прежнему загружает страницы линий, а детали — выбранную линию. Фильтры/группировка столбцов обзора относятся к показанной странице; верхний поиск и штатные сводки охватывают весь серверный отбор. Новый интерфейс не загружает весь проект ради клиентской группировки.

| Локальный сценарий | Измерение после переноса |
| --- | --- |
| Полный список под клеймом: 50 / 120 / 500 стыков | Раскрытие 284 / 424 / 1326 мс; 1466 / 3286 / 13166 DOM-элементов; внутренней вертикальной прокрутки нет |
| Два одновременно раскрытых клейма с общими 500 стыками | 26320 DOM-элементов; JS heap страницы около 115 МиБ после сценария против 12,5 МиБ перед раскрытием |
| Окно назначений, 500 / 1000 стыков с документами | Открытие 2,14 / 2,72 с; поиск 45 / 53 мс; проверка и сохранение одной правки 459 / 605 мс; DOM виртуализирован |
| Получение 500 стыков по HTTP | 302 мс и 931758 байт против исходных 202 мс и 929758 байт; ускорение не заявляется |

Это отдельные локальные измерения, не гарантии для production. JS heap измерен без принудительной сборки мусора и не равен памяти процесса. Полная высота списков под клеймами сознательно увеличивает DOM и память относительно прежних 50 строк на странице; несколько больших раскрытых клейм увеличивают стоимость пропорционально числу показанных строк.

Регрессии подтверждают один запрос расчёта и один запрос строк при раскрытии/повторном раскрытии нескольких клейм, отсутствие новых RPC при прокрутке, focus/online, ограниченный повтор чтения после сохранения и постоянное число SQL при переименовании линий с 1 и 2000 стыков. Новых обращений к серверу в рендерах строк нет. Свежий ресурсный/многопользовательский прогон на 200000 стыков **не выполнен**; соответствующий opt-in E2E пропущен. Это остаётся отдельным объёмом системного аудита, а не подтверждённым результатом переноса.

Закрепление реальных заголовков изолировано в `line-program-sticky-headers.tsx` и проверено прокруткой вниз/вверх, изменением ширины и фильтрацией. Оно использует DOM AG Grid 36, поэтому обновление AG Grid потребует повторения этих регрессий. Сохраняются прежние предупреждения сборки о крупных чанках и AG Grid Enterprise при отсутствии локального ключа; лицензирование этим изменением не исправлялось.
