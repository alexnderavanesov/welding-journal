### Бизнес решения которые нужно сохранить

- Итоговые результаты требуют названия и применимой фактической даты; в дубль-контроле обязательны обе независимые даты. Старую неполную историю не исправлять выдуманными реквизитами и не скрывать; несвязанные правки допустимы, исправление самого результата/перенос требуют полноты. Послойные реквизиты генерируются автоматически, нового ручного ввода нет.
- Специалисты: НК/ТВМТ — «Провёл контроль» и «Выдал заключение»; ПСТО — «Оператор-термист» и «Руководитель по ТО». Роли необязательны, один человек может занимать обе. Общая пара при создании плюс индивидуальные поправки документа; после создания менять только через «Документы». Дубль-контроль, заявки, ЖСР, чек-листы и ЗНИ назначениями не расширялись.
- ФИО и удостоверение сохраняются в документе снимком; правка/архив карточки историю не меняет. Архив исключён из новых назначений. Общая пара запоминается отдельно для ВИК/РК/ПВК/УЗК/ТВМТ/ПСТО только после успешного создания; отмена и индивидуальные поправки её не меняют. Восемь семантических полей конструктора, видны только подходящие типу шаблона.
- Одно окно «Назначить специалистов» без режимов: каждая роль «Не изменять», назначить/заменить либо очистить. Действует на весь явный выбор, атомарно, с проверкой квалификации, версии и полного состава документов. Разные ID карточек с одинаковыми сохранёнными ФИО и удостоверением означают одинаковую подпись.
- При объединении разных подписей — предупреждение и после подтверждения очистка обеих ролей конфликтующего итогового документа. Обычный перенос, переименование и разделение сохраняют снимки; остальные позиции общего документа не теряются. Изменение состава после подтверждения требует нового подтверждения.
- **Все четыре сценария ПСТО единообразны:** назначение/возобновление и переезд на назначенную линию предлагают основной НК → до ТО; отмена и переезд на неназначенную/отменённую — до ТО → основной. Default KEEP, отдельно для стыка, весь имеющийся комплект, включая заявки без результата. Перенос требует пустого целевого этапа, реквизитов, хронологии и допустимой официальности; собственные зависимости ПСТО/ТВМТ и циклы защищены. История соседнего стыка не заменяет историю этого стыка. Отдельной кнопки произвольной смены этапа нет.
- В редакторе результатов ЛНК замены/удаления применяются только при сохранении с общей сводкой «стык, метод, было → станет», включая скрытые фильтрами позиции. Закрытие/отмена не удаляют данные; отдельного сохранённого черновика нет. Конфликт отклоняет весь пакет и сохраняет ввод в открытом окне.
- На неофициальном стыке разрешено довнести «годен» по другому методу, если негодный результат остаётся. Исправлять сам сохранённый брак на «годен» нельзя. Возврат официальности объясняет конфликт с официальным тёзкой. После допустимого удаления тёзки проверены восстановление и правильное будущее продолжение. Смешанная цепочка хранит непосредственного предшественника, например `S63W1R1 → S63W2R1`; старые связи автоматически не переписываются.
- Осмысленное удаление — штатный процесс, но не разрешение удалять произвольную середину цепи или автоматически уничтожать потомков. Действующие защиты предшественника/основания катушки сохраняются. Удаление результата, документа, справочной записи и всей записи стыка — разные операции с их собственными зависимостями.
- У заявок ЛНК две последовательности по этапам; у заключений — пара для каждого метода. Новые последовательности начинают с прежнего следующего номера и дальше независимы. Формула «До ТО» первоначально наследуется с «ДО-ТО»; старые имена/номера не меняются. Сброс выбранного этапа не разрешает дубли занятого имени. Выбор начальной вкладки удалён из настроек; ручные имена в формах остаются.
- Восстановление файла шаблона сохраняет настройки конструктора при совместимости; настоящая защита версий остаётся. Публикация/чтение/очистка согласованы блокировками, ошибку уборки после успешного COMMIT не выдавать за неудачное сохранение. Не терять резервные файлы отсутствующего активного шаблона. Рабочие файлы и production автоматически не восстанавливались.
- Обычный поиск работает по всей подходящей базе, не по загруженным 100 строкам. Строки отделены от сводок; возможна надпись подсчёта, но итоговые фильтры и сохранения ждут актуальных проверок. Массовые действия и экспорт сохраняют полный явный состав, поздний ответ не подменяет новую выборку. При неопределённости зависимостей остаётся полный пересчёт.
