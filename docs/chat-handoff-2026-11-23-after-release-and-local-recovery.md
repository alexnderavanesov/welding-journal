Ориентир — **дата заключения**, не сварки (кроме действующего отдельного послойного процесса). Подходящее датированное удостоверение приоритетнее бессрочного; обе даты или ни одной; для одного метода пересечения включительных периодов и несколько бессрочных запрещены. Нет подходящего — нет нового назначения. Массовое назначение проверяет все документы, номер сохраняется отдельно для каждого. Старые карточки/снимки не переписываются; явное новое назначение проверяется по новым правилам.
- [Единые окна и проверки](precommit-audit-2026-11-20.md): вкладки «Стыки»/«Документы» для заявок/результатов ЛНК основного этапа и до ТО, ПСТО/ТВМТ и повторов; доступна общая история ТВМТ. В документе дата/название относятся ко **всему сохранённому составу**; ошибка хронологии хотя бы третьего, не выбранного стыка отменяет всю запись. Результат относится к выбранной позиции. Отдельный перенос позиции в другое заключение показан только при нескольких позициях, с понятным пояснением; одно переименование всего документа состав не меняет. Через общий раздел «Документы» новый редактор не добавлялся.
- Рабочие редакторы используют права **ЛНК/ПСТО**, дополнительный доступ в общий раздел «Документы» не требуется; чужие этапы и отзыв права защищены на сервере. Выключенный НК до ТО не требует проверки дат старой истории; после включения ранее пустого этапа обычные проверки сразу действуют. Сохранять версии/конкуренцию, атомарность, подтверждения и историю.

Текст имеет свою вкладку, масштабируется с чертежом, начальный поворот 90° по часовой, приглушённую выноску; сначала наконечник, затем положение текста; размер рамки изменяем на чертеже.

При отдельно разрешённой реализации сохраняется постоянное разрешение **проверенных локальных миграций на main** с сохранением данных: schema.ts → `pnpm db:generate` → просмотр → `pnpm db:migrate`. SQL вручную не писать. Fixtures/load/restore — отдельная проверенная пустая локальная одноразовая БД, не `welding_tracker`. Remote — отдельное разрешение, выделенные реквизиты и штатная `pnpm db:remote-migration`.
4. Перед каждым отдельно разрешённым production push/deploy — свежий локальный резерв в паузу записи, проверка читаемости, закрытые права, без S3 PDF. Репетиции нужны для крупных изменений/миграций; не обещать restore свежей копии, если было только чтение dump.
