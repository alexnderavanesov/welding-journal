## Решения, обязательные для будущего ЛНК

- Эталон — **текущий сварочный журнал**, включая последующие небольшие исправления, и проверенная общая основа ПСТО. Не исходный прототип, не Документы и не программа линий. Полная база: [журнал](ag-grid-welding-journal-2026-10-15.md), [план и результат ПСТО](psto-ag-grid-implementation-plan-2026-10-19.md).
- Пользователь отменил предложение считать строки: групповой счётчик — **физические соединения**. S1 → S1R1 → S1R2 — одно; заменённый катушкой корень исключается, две стороны считаются отдельно. Выбор галочками/операции остаются по записям. Фильтры/сортировка — вся серверная выборка, группы — загруженная часть. Неполная цепочка не выдаётся за достоверно годную; ошибка истории сохраняет приоритет, исправленный прежний брак не делает годную текущую цепочку бракованной.
- Итог конкретного метода/этапа ЛНК нельзя подменять общим итогом стыка. Сохранить заявки, контроль до/после ТО, циклы, результаты, документы, специалистов, официальность, хронологию, права и серверные проверки. Соответствие столбцов/действий и новые специфические итоги ЛНК сначала обсудить.
- Четыре сценария ПСТО/НК: назначение/возобновление, перенос на неназначенную линию, отмена программы, перенос на назначенную. Последние согласования важнее старого запрета переноса: исходно сохранение истории, выбор по стыку и полным доступным комплектам, включая заявки без результата; проверка целевой истории/хронологии/связей. История соседнего стыка не заменяет свою. При конфликтующем объединении документов сбрасываются обе роли специалистов только конфликтующего документа, остальные снимки сохраняются.
- «Не требуется» не означает «запрещено»; ожидание не доказывает начало процесса. Недостижимая теоретическая квота не становится долгом назначения. Системные поля меняются только профильными процессами; частичный импорт проверяет итоговую объединённую запись и все обнаруживаемые ошибки. Не ослаблять атомарность, concurrency и защиту предшественников/катушек.
- Текущий вывод журнала/ПСТО — видимые столбцы в экранном порядке по всей отфильтрованной серверной выборке, без UI-групп. Будущая группировка экспорта отдельно не согласована.
