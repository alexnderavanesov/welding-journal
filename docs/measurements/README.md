# Архив подробных замеров журнала

По поручению пользователя 22.10.2026 подробные JSON вынесены за пределы Git. Сохранены **18 файлов, 265225 строк, 8205856 байт**. SHA-256 каждой копии проверен перед удалением исходника; контрольные суммы и имена находятся в `manifest.json` архива. Код и необходимые тесты сохранены.

Локальный архив относительно корня проекта: `../welding-journal-local-measurements/2026-10-22-precommit-archive/`. Он не включается в коммит и доступен только на этом компьютере. Полная прежняя хронология (139691 байт) сохранена там же как `journal-implementation-history.md`, контрольная сумма — в `history-manifest.json`. Исторические ссылки с именем JSON ведут сюда; файл с тем же именем находится в архиве.

Краткие результаты и ограничения:

- [Реализованное поведение и последовательность замеров](../ag-grid-journal-server-2026-10-21.md).
- [Текущая очистка и предкоммитная проверка](../precommit-audit-2026-10-22-cleanup.md).
- [Предыдущая предкоммитная проверка](../precommit-audit-2026-10-22.md): исторические результаты, не подтверждение следующих правок.
- [Объединение событий ширины](../journal-scroll-resize-investigation-2026-10-22.md) и [стоимость отрисовки](../journal-layout-cost-investigation-2026-10-22.md): экспериментальные изменения отклонены, устойчивого выигрыша без ухудшений нет; их архивы указаны отдельно.

Полный комплект текущей проверки сохранён в подкаталоге `checks/` того же архива: логи, трассы ошибок и свежие замеры. `checks/manifest.json` содержит контрольные суммы; `checks/verification.json` — результаты, ограничения и контрольные суммы проверенного исходного кода. Неудачные прогоны также сохранены для диагностики.

Последующая проверка увеличения локального `/dev/shm` до 1 ГиБ сохранена отдельно: `../welding-journal-local-measurements/2026-10-22-shm-1gb/` относительно корня проекта. `manifest.json` содержит контрольные суммы. Семь сценариев на 200000 стыков прошли без отключения параллельного hash; подробности — в текущем отчёте очистки.

Замеры до/после облегчения готового кэша фильтра: `../welding-journal-local-measurements/2026-10-22-filter-cache/`. Краткий [результат и ограничения](../journal-filter-cache-2026-10-22.md) остаются в проекте.

Замеры RAF не равны физическому FPS экрана. WebKit отдельно от установленного Safari; прогоны с фоновым окном/блокировкой не использованы для выводов о плавности.

Повторная предкоммитная проверка переноса от **23.10.2026**: [результат и ограничения](../precommit-audit-2026-10-23.md). Архив — `../welding-journal-local-measurements/2026-10-23-precommit-archive/`: предыдущие записи/кадры и подкаталог `checks/` с результатами завершённой проверки, включая успешный повтор клавиатуры и настоящего буфера установленного Safari в `native-safari-followup/`. Копии проверены SHA-256; суммы находятся в `prior-measurements-manifest.json` и `checks-manifest.json`, результаты и область применимости — в `checks/verification.json`, отпечатки проверенных исходников — в `checks/source-complete-manifest.json`. Эти данные остаются вне Git.
