## Выполненные функции и важные правила

Актуальные источники: [реализация НК 12.11](pre-heat-treatment-update-2026-11-12.md), [полный план НК](pre-heat-treatment-modes-plan-2026-11-06.md), [документы/Excel](document-registry-report-2026-11-12.md), [окна фильтров](filter-windows-2026-11-12.md), [схемы и полинейная сводка](line-schemes-plan-2026-11-09.md). Их исторические «не выпущено / требуется подготовка» заменены завершённым выпуском выше.

- Массовые НК до ТО — только в ЛНК: кнопка после «Официальность» и ПКМ. Постановка/снятие охватывают явно показанную R/W-цепочку, повторный выбор звеньев её не дублирует; стороны катушки самостоятельны. Отдельное «Заполнить недостающее как „Годен“» работает только с выбранными применимыми записями с отметкой; не включает скрыто остальные звенья. Совмещённая постановка с заполнением показывает полный затрагиваемый состав.
- Снятие показывает удаляемые позиции/документы, сохраняет другие этапы и чужие позиции. Предварительный текущий «Ремонт»/«Вырез» блокирует; основной брак сам по себе не блокирует. Хронология, зависимости **заявка → ВИК → ПВК → РК/УЗК**, права, актуальность просмотра, атомарность и сохранение прежних результатов обязательны.
- Выбор режима убран: всегда выборочно. Новый независимый стык без отметки по умолчанию; при выбранной в черновике линии с ПСТО её можно включить сразу, смена идентичности линии сбрасывает ручной выбор. R/W наследуют отметку. Смена линии сохранённой цепочки не удаляет автоматически историю.
- Столбец после «Назначение ПСТО» в СВЖ/ПСТО/ЛНК: **«—» слева** — неприменимо, **пусто** — выключено при ПСТО, **«Да»** — включено; подсказки и понятные имена фильтра. Сохранённая отметка без текущего ПСТО остаётся «Да» с пояснением. Старое описание двух состояний в плане заменено этим уточнением.
- В документах «Показать» использует вкладку, фильтры, порядок и столбцы; ограничен только предпросмотр. Excel полный, свежие данные при скачивании с захваченными настройками; preview/печать сохраняют снимок. Печать уже реализована, не отменять и не вводить новые лимиты/очереди без выбора.
- Сводка: «Состав» после «Выполнение, стыки», F/S/ОП, ОП входит в объём/выполнение/остаток; процент на схеме и два бейджа (линии с PDF, физические стыки на схемах), все бейджи в ряд. Старый NaN/пустая таблица исправлены через версию кэша, данные не терялись. Фильтры схем — все девять столбцов, файлы/архив по количеству редакций. Окна фильтров растягиваются, прежние пояснения об области отбора убраны. Активность без входа — «Ещё не входил».
- Не переоткрывать закрытое правило У19: D/T стороны меньшего диаметра, при равных D — меньшая T; 57×6 + 159×3 → D57/T6. Подбор ТК отдельно. Клейма — две официальные/фактические пары, не слои; для Т только первая. Т/ОП, авторизация, выбранные оптимизации, схемы/S3 и пользовательские документы уже реализованы и выпущены.
