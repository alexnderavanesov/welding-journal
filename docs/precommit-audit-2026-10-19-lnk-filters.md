## Исправления проверки

- Воспроизведена неправильная сортировка WDI: SQL использовал сохранённое число при отображении текущего расчётного. Теперь сортировка трёх отчётов использует выбранный режим WDI до границы страницы; кэш учитывает настройки и для сортировки. Регрессия проверяет формулу, таблицу, ручной режим, оба направления, две страницы, обычный/расчётный фильтр и полный вывод. Руководство дополнено.
- Воспроизведён неверный выбор цикла ПСТО для старых пробельных значений: пустая диаграмма/реквизиты позднего повтора считались выполнением и вытесняли фактический основной цикл. SQL теперь использует ту же очистку пробелов, что отображение; отдельно проверены пробельные реквизиты, окружённый пробелами результат, отсутствие назначения и отмена. Факты не переписываются. Девять SQL-регрессий после исправления прошли.
- Из контракта и передачи параметров удалены неиспользуемые настройки прежней HTML-таблицы. Из общих ячеек/кнопок убраны недостижимый HTML-режим и старые CSS-помощники закрепления. Рабочие обработчики сохранены; 26 проверок ссылок и действий прошли. Пять тестов удалённого оформления HTML-таблицы убраны; выделение/закрепление AG Grid проверяется действующим браузерным контрактом. Старое ожидание редактирования одним кликом заменено действующим поведением AG Grid: один клик выделяет, двойной редактирует (реальный ввод/сохранение покрыт `lnk-defect-descriptions`).
