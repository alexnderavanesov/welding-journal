## Ограничения

- **Без агентов**, экономия токенов важнее ускорения. Не менять модель/настройки нового чата. Делегирование только после отдельного согласования конкретной пользы.
- Без нового прямого поручения — только чтение и ожидание. Не коммитить, не пушить, не деплоить, не менять ветку, не создавать worktree, не stash/reset; сохранять рабочие данные и незакоммиченные файлы. Передача не повторяет разрешение на завершённый коммит.
- **Прод не трогать.** Production — среда реальных пользователей. Любое изменение БД, файлов, документов, настроек, Coolify, контейнеров, сервера или push с автодеплоем требует прямого разрешения конкретного действия. Read-only доступ не разрешает тесты, нагрузку или скрытые записи. При чтении контекста прод не открывать.
- При отдельно разрешённой реализации сохраняется постоянное разрешение на проверенные **локальные миграции**, включая рабочую БД: main, точный локальный адрес/имя, сохранность данных, Drizzle schema → generate → просмотр → штатный migrate. SQL миграций вручную не писать. Remote migration требует отдельного разрешения и штатного `pnpm db:remote-migration`.
- Fixtures/нагрузка/автоматические проверки — только отдельная пустая локальная БД и временное хранилище. Основная `welding_tracker` не тестовая. Штатный `e2e/run.ts` использует `127.0.0.1:5432/welding_tracker_e2e`, отказывается заменять существующую БД и удаляет только созданную им. Два чата делят checkout: не запускать параллельные редактирования/runner с одной disposable-БД.
- Прототип 4318 отслужил задачу и остаётся выключенным. Сохранить `prototypes/dispatcher-line-program/README.md`, `backups/line-program-parity-20261015-184148/prototype.tar.gz` и `backups/dispatcher-layout-2026-10-15-173527/paused-layout-draft/`; наличие проверено.
