**Репетиция завершена. Проверены все 9 432 записи: прежние назначения без основания не блокируют несвязанные правки, **63 неофициальных стыка** не расходуют лимит ремонтов, назначения **7 продолжений R/W** соответствуют непосредственным родителям. **56 старых назначений** «Дополнительный»/«Отменен» без основания оставлены как есть. Через штатный API на **12 реальных записях из копии** проверены сохранение/возврат примечания, 12 отказов устаревшим клиентам и запрет снятия наследуемого РК. Разобраны штатные отличия: одна устаревшая подпись ожидания ПСТО нормализована по уже имеющейся заявке, обновлены служебные даты и у четырёх предварительных документов добавлен производный список ID без изменения состава или исторических позиций. ## Ограничения и завершение

Проверена совместимость именно этого снимка с текущим кодом. Файлы шаблонов, производственные SMTP/Postbox, HTTPS, прокси, ресурсы сервера и фактическое развёртывание сюда не входят. Проверка настроек шаблонов в БД не заменяет проверку самих файлов. Исторических Т в выгрузке нет; их функциональная проверка выполнена ранее в предкоммитном аудите на отдельных наборах, вымышленные старые ОП сюда не добавлялись.

Собственный сервер 3127 остановлен; обе одноразовые базы удалены с проверкой имён, OID и отсутствия подключений. Основной локальный сервер 3000 сохранён, рабочая база не использовалась для фикстур. Приватные сценарии, исходные диагностические отказы и итоговые сравнения: `outputs/upgrade-rehearsal-2026-11-05/`, вне Git. Начальные строгие сравнения помогли отдельно разобрать инициализацию ПСТО и служебные изменения при сохранении; код приложения под результаты проверок не менялся.

После завершения репетиции пользователь отдельно поручил **локальный коммит** проверенного объёма. Выпуск в production по-прежнему требует отдельного разрешения, свежего резерва и окна обслуживания; push с автодеплоем, полная штатная подготовка БД и проверка готовности составляют один согласуемый выпуск.
