Обновление на 25.09.2026: решения промежуточной задачи сведены в [план «Программы линий»](line-program-plan-2026-09-25.md). Реализация ещё не начата. Для С/У уточнены общий базовый процент РК/УЗК и отдельный общий процент ПВК; старое описание независимого ввода каждого метода ниже отражает ранний этап обсуждения и не заменяет новые решения. Исключение Т из добора подтверждено; исходные вопросы Т возвращаются после реализации промежуточной задачи. Пользователь отложил проверку нормативных источников: правила сейчас рассматриваются как его требования, а не независимо подтверждённые нормы.

По просьбе «давай продолжим задачу по Т стыкам» сначала изучить уже реализованные новые правила назначения контроля, затем вернуть актуализированный список оставшихся вопросов и добавить обнаруженные противоречия. Старые предположения о механизме назначения не считать утверждёнными.

## Подтверждено пользователем

- Семейство типов с кириллической «Т» (Т, Т1, Т3, Т4д и т. п.) описывает соединение трубы с опорой. Конкретные типы задаются существующим справочником.
- Номер начинается с кириллического «ОП», далее допустимы свободные комбинации: ОП44, ОП-44, ОП-44-1, ОП44/3. Ограничение системного суффикса ремонта ещё не согласовано.
- Переход сохранённой записи между Т и другими группами запрещён, включая редактирование и импорт. Переход внутри Т, например Т3 → Т4д, разрешён.
- У Т используются D1 и T1 трубы, а также итоговая длина шва L. По D1/T1 действуют проверки НАКС, ДЛС и отстранения сварщика. Пользователь предпочитает расширить существующие ЗВ/ДЗ допуска.
- Единое поле «Длина шва, мм»: для С/У автоматически min(D1, D2) × 3,14; для Т — ручная суммарная длина всех швов данного соединения. ВДИ для Т не рассчитывается. В конструкторе документов выбирается это поле без условной формулы по типу.
- Ручная длина может быть пустой или положительной. Поведение неполного расчёта при пустой длине ещё не согласовано; обязательность при дате сварки не утверждена.
- Результаты НК Т: «годен» или «ремонт». Вырез, катушка, ограничение количества ремонтов и запрет ремонта при диаметре меньше 89 мм не применяются. Пример: ОП3R5 допустим как ремонтная запись.
- Ремонт наследует полную длину соединения: ОП3 = 600 мм → ОП3R1 = 600 мм, даже если ремонтировался меньший участок. Учёт этих строк в статистике и процентной базе ещё нужно определить.
- РК и послойный контроль запрещены во всех точках входа, включая дубль-контроль, импорт и смешанные заявки. ВИК обязателен после сварки.
- ПСТО/ТВМТ применяются по назначению линии. Правила НК до ТО и настройки раннего основного НК действуют как для остальных соединений.
- ОП входят в ЖСР, чек-листы и ЗНИ. Они исключаются из производственных счётчиков стыков/ВДИ в левом верхнем углу отчётов и обычного расчёта процентных линий.
- На момент обсуждения Т/ОП ещё нет ни локально, ни на production; перевод существующих опор из С/У не требуется.

## Подтверждённый смысл назначения контроля

Источник требований для системы — проценты контроля по каждому методу НК, которые вводит пользователь. Организация этого ввода и применение значений к стыкам, процентным расчётам и ДЗ составляют промежуточную большую задачу; её интерфейс, модель данных и правила ещё предстоит согласовать. Анализ чертежей или автоматическое получение требований из проекта не запрошены. ВИК всегда 100%. Прежнее правило равных назначений на 100%-ной линии — контекст существующей реализации, а не окончательная спецификация нового механизма.

Для Т требуется независимый расчёт длины УЗК и ПВК по каждому клейму на каждой линии. Минимум каждого метода — 0,5%; при большем проектном требовании данного метода применяется оно. Пользователь подтвердил всю таблицу:

| Требование линии | УЗК Т | ПВК Т |
| --- | --- | --- |
| 100% УЗК, ПВК не назначается | 100% | 0,5% |
| 30% УЗК и ПВК | 30% | 30% |
| 30% ПВК, УЗК не назначается | 0,5% | 30% |
| Назначается только РК | 0,5% | 0,5% |

Негодный результат Т не увеличивает процент контроля. Переход клейма в 100% контроль по обычным стыкам не распространяется на Т. Отмена назначения допустима; точный способ её зачёта ещё открыт. Заявленное нормативное основание 0,5% требует номера/пункта ГОСТ, оно не подтверждено независимо.

Пользователь предложил отдельную вкладку «Опоры» в разделе «% линии» с назначениями, отменами и остатками УЗК/ПВК для всех линий с Т, включая 100%-ные. Для статистики предложены либо расширение переключателя F/S/ОП, либо компактная вкладка «Опоры» перед полинейной сводкой; рекомендован второй вариант, окончательный выбор не подтверждён.

## Вопросы для возобновления

1. После промежуточного обновления: применить согласованный пользовательский ввод процентов по методам к расчёту Т и уточнить только оставшиеся особенности. Отдельные ручные нормы опор ранее лишь предлагались, но не утверждены; они могут оказаться не нужны после нового общего механизма.
2. Контроль назначается на всю длину выбранного ОП или можно назначить часть (50 из 600 мм)? Во втором случае нужна длина контроля отдельно по методам. Уточнить допустимое превышение минимума при выборе целого ОП.
3. Отмена с основанием закрывает требуемое назначение или требует выбрать другие опоры? Разделять назначенный, отменённый и фактически выполненный контроль.
4. При пустой L разрешать сохранение с ДЗ и пометкой неполного расчёта? Не принимать неизвестную длину за ноль и не объявлять расчёт закрытым.
5. При нескольких различных клеймах полная длина относится к каждому или делится на доли? Повтор одного клейма в разных полях не должен умножать его объём.
6. Как учитывать ремонты в базе процента и статистике, особенно при смене сварщика? Полная L ремонтной записи уже согласована; её повторный учёт — нет.
7. Какие этапы закрывают фактический объём: основной НК, до ТО, дубль? Как исключать повторный зачёт одной длины без скрытого изменения требований к этапам?
8. Резервировать ли окончание R + число для системного ремонта, сохраняя свободное базовое имя ОП? Как применить существующие настройки системного индекса ремонта?
9. При исправлении L исходного ОП обновлять ли всю ремонтную цепочку одной операцией и как учитывать связанные документы?
10. Для С/У с одним заполненным диаметром брать его или оставлять L пустой? Уточнить точность длины/процентов и округление без уменьшения обязательного объёма.
11. Номер и пункт нормативного документа для минимума 0,5%, включая применимость к методам и этапам.
12. Утвердить границы отдельной статистики опор. Прежняя фраза о «готовности линии» была уточнена: текущая полинейная сводка показывает сварено/осталось по дате сварки, а не приёмку всех этапов. Новый запрет закрытия линии не согласован.

## Контекст разработки

Предыдущее выполненное изменение — даты в сообщениях о конфликте хронологии — остаётся отдельным незакоммиченным набором изменений. Его нельзя потерять или принять за реализацию Т.

Работа и проверки локальные; production допускает только просмотр без изменения состояния. Миграция нового поля потребуется при реализации. Целевой масштаб — 200 000 записей; большой отдельный прогон отложен, проверки сложности и количества запросов остаются обязательными. Пользователь просит собирать все вопросы в конце одного сообщения и писать отчёты по существу.
