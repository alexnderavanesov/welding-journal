## Результат

- В журнале, ЛНК, ПСТО и реестрах документов копируются только значения ячеек. Названия столбцов и служебные пустые строки между диапазонами больше не добавляются. Сохранены порядок столбцов и строк, объединение совместимых пересечений, незагруженные строки, запятая в дробных числах, отмена при смене выборки и защита от частичного результата. Убраны ставшие ненужными признаки заголовков в описании диапазонов. Руководство обновлено.
- Предупреждение React при первоначальной загрузке воспроизведено отдельным браузерным тестом. Причина: текст функции восстановления получался через `toString()`, а серверная и браузерная сборки различались лишней точкой с запятой. Теперь обе стороны используют один исходный текст JavaScript; сама функция восстановления, ожидание полного ответа, ограничение времени и однократная перезагрузка сохранены. Тест до исправления упал, после — прошёл без ошибок консоли. JavaScript отдельно проверен TypeScript с `checkJs`.
