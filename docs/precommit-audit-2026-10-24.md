## Найдено и исправлено

- Добавлена небольшая серверная диагностика PDF: кеш/общее задание, время очереди и подготовки, успех/ошибка/отмена. Нет содержимого, названий, хешей документов и новых запросов к БД. Ошибка диагностики не прерывает работу.
- Полный unit-прогон выявил устаревшую проверку `allow-scripts` в отчёте программы линий. Для согласованного масштабирования в WebKit обработчики родителя требуют этот флаг; выполнение скриптов самого документа запрещает CSP. Проверка уточнена по требованию безопасности, браузерный сценарий проверяет реальную блокировку inline/external script и внешних ресурсов.
- PDF.js обновлён с уязвимой 5.6.205 до 6.2.108 ([advisory](https://github.com/mozilla/pdf.js/security/advisories/GHSA-hq66-cqwq-w95j)); выполнение PDF-сценариев явно отключено. Удалён отсутствующий в API 6 параметр, тестовое чтение PDF освобождает loading task. Для dev-зависимости undici установлена 7.30.1. Production dependency audit: 0; общий — только прежнее исключение moderate для внутреннего esbuild CLI Drizzle, новых исключений нет.
- Проверка внешних ресурсов XLSX использовала регулярное выражение: пробелы, XML-сущности и кодировка могли обойти запрет. Заменена разбором XML; DTD запрещён, обычные ссылки и встроенные изображения сохранены. Пять новых контрпримеров сначала падали; после исправления все семь проверок проходят. Парсер включён в Docker.
- В ЛНК/ПСТО причина блокировки во время обновления выбранных стыков могла не отключать кнопку сохранения. Общий footer теперь учитывает эту причину; регрессия сначала падала, после исправления все шесть тестов footer проходят. Браузерные сценарии задержанных ответов дополнены проверкой кнопки.
- При заполнении Excel терялся `sheetPr/pageSetUpPr`, включающий вписывание по ширине: пустой настроенный чек-лист помещался на странице, а заполненный снова делился горизонтально. Флаг сохраняется вместе с параметрами печати, без замены остальных свойств листа. Регрессия воспроизведена до исправления; проверены и конструктор, и маркеры. Руководство дополнено.
- Уточнены устаревшие E2E: проверяется фактический PDF и его байтовое совпадение с печатью вместо прежнего HTML. Счётчики RPC учитывают согласованную сводку стыков по области, сохраняя верхние границы запросов. Для тестовых Excel заданы ширины, позволяющие увидеть полные контрольные значения. Устранены гонки тестов: колесо отправлялось до загрузки значений фильтра или окончания разгруппировки, большая SQL-фикстура не обновляла ревизию производных данных. Бизнес-ожидания не ослаблены.
- Удалены оставшаяся кнопка «Снять выбор» в документах, недостижимая ветка предпросмотра и устаревшая экспериментальная обёртка конвертера. Бенчмарк вызывает рабочий скрипт.
