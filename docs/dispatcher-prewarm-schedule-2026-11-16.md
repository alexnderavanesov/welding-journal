# Автоматическая утренняя подготовка — 16.11.2026

**Готово локально.** По последнему поручению пользователя ежедневная проверка в **06:30 Europe/Moscow**, включая выходные, включится при развёртывании Docker-образа с этими изменениями. Отдельно устанавливать cron или Scheduled Task в Coolify не нужно. Работающий production не менялся; коммит, push и выпуск не выполнялись.

## Поведение

- Серверный плагин ставит один таймер до следующего запуска. При старте нет расчёта или обращений к БД из планировщика; между запусками нет опроса. Docker включает `DISPATCHER_PREWARM_ENABLED=1`, явное `0` отключает расписание. Development и обычный локальный запуск без флага остаются без расписания.
- В назначенное время вызывается существующий `prepareDispatcherCalculation`: сначала готовность выпуска, затем актуальность по данным, версии правил и московской дате. Готовый результат используется без повторной публикации; необходимый частичный/полный расчёт выбирает прежний алгоритм. Его блокировки объединяют пользовательские, операторские и одновременные запуски разных процессов.
- Внутреннему вызову не нужен секрет HTTP-команды. Защита внешнего maintenance-эндпоинта сохранена; ручная команда по-прежнему требует токен. Дополнительный индекс отключённых фоновых кодов не включается.
- Ошибка отмечается в журнале сервера без нового цикла повторов; обычный пересчёт при обращении к данным сохраняется. После пропущенного времени/перезапуска ожидаются следующие 06:30, без очереди пропущенных дней. Это время начала проверки, не гарантия готовности. При завершении сервера таймер снимается.
- Схема БД, версия правил, механизм публикации и раннее редактирование при пересчёте не менялись. Обновлены встроенное руководство, README и пример альтернативного внешнего cron. Новых зависимостей нет.
