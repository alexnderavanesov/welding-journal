# Состав стыков в реестрах документов — 19.11.2026

Добавлен столбец после «Стыков» во всех системных заявках/заключениях ЛНК, ПСТО, ТВМТ и в послойном контроле. Названия берутся из сохранённого состава документа, включая исторические стыки; одинаковые названия разных стыков сохраняются. ЖСР, чек-лист и ЗНИ в этот запрос не входили.

Последующее решение пользователя: столбец работает как обычный. Поддержаны общий поиск, поиск значений и выбор нескольких значений в фильтре, пустой состав, сортировка, группировка, сохранение настроек, копирование и вывод списка в предпросмотр/Excel. Галочка фильтра выбирает полный текст состава; поиск находит вхождение текста. Условия применяются в SQL до ограничения блока, а не только к загруженным строкам. Руководство обновлено.

При обычном просмотре состав вычисляется для запрошенного блока. Поиск без пробелов проверяет имена связанных стыков; предварительная общая проверка пропускает обход связей, если совпадающих имён вообще нет. Поиск фраз, фильтрация, сортировка и группировка по составу используют полный текст кандидатов всего реестра в том же SQL-запросе. Новые таблицы, миграции, постоянный кэш и запросы из браузера на каждый документ не добавлены. Существующая ревизия журнала защищает последовательное чтение от переименования стыка.

Последующие исправления длинных фильтров, проверка на 600 тысячах документов и итоговая предкоммитная проверка записаны в [отдельном отчёте](precommit-audit-2026-11-19.md). Результаты ниже относятся к первоначальному этапу этой функции.

Проверено локально: 89 модульных проверок, проверка типов (включая отдельную проверку E2E), сборка; 8 сценариев Chrome и 6 WebKit успешно завершены с целевыми повторами после исправлений тестов. Новые случаи используют 121 документ на реестр: нужные значения за первой сотней, пустые/множественные значения, сочетания условий, поиск вариантов с другими фильтрами, сортировка, группы, ID, копирование, Excel и настройки после перезагрузки. Первое ожидание сортировки исправлено: пустой текст идёт первым по возрастанию, как в других текстовых столбцах. В WebKit тест теперь ожидает штатную запись снимка настроек и закрытие предпросмотра перед перезагрузкой; код общего восстановления позиции не менялся. Нагрузочный прогон на сотнях тысяч документов и полный предкоммитный аудит здесь не проводились.

Артефакты: `outputs/document-joint-composition-2026-11-19/`. Все фикстуры использовали отдельную локальную `welding_tracker_e2e`, удаляемую runner после проверки. Локальный Vite снова отдавал старые модули: перезапущен только процесс этого проекта на 3000, актуальные ответы проверены по HTTP. Прод, commit и push не затрагивались.
