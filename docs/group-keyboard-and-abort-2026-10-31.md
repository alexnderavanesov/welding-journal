# Enter/F2 в группах и локальное окно aborted — 31 октября 2026

Исправлены два подтверждённых дефекта после [проверки галочек](checkbox-focus-2026-10-31.md).

**Фокус группы.** Обработчик Enter/F2 принудительно выбирал столбец с названием группы («Линия»), оставляя прежнюю рамку диапазона. Теперь раскрытие/сворачивание сохраняет исходный столбец и снимает старую позиционную область. Отмеченные стыки сохраняются. Правка общая для ЛНК, ПСТО и сварочного журнала; руководство обновлено. Видео пользователя просмотрено по извлечённым кадрам. До исправления новые проверки падали во всех трёх журналах: ожидался исходный столбец, получалась «Линия».

**aborted.** На отдельном dev-сервере воспроизведена гонка: HTTP-запрос уже получен целиком (`complete=true`), но соединение закрывается до завершения чтения адаптером. Прежняя защита считала этот признак основанием показать ошибку. В диагностике подтверждены `aborted=true`, закрытый ответ, `ECONNRESET` и стек Node `abortIncoming`. Убрано только ограничение по `complete`; остальные проверки сохранены. Ошибки базы/приложения и ошибки живых соединений не скрываются. Обработчик относится только к Vite dev, production-код не менялся.
