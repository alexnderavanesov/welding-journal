Реализация локальная, без миграций. Коммит, push и изменения production не выполнялись. Предшествующий аудит и углублённая оптимизация остаются завершёнными; эта задача их не возобновляет.

## Принятые правила и результат

- Только во вкладке **«Общая»** каждое действующее физическое соединение считается один раз. R/W не добавляют повторный объём; актуально негодные исключены из выполненного объёма. Учитываются устойчивые связи цепочек, не только суффиксы; две стороны катушки остаются двумя соединениями.
- Период определяется датой сварки актуальной записи. Исходный стык в сентябре и его ремонт в октябре дают зачёт в октябре; в сентябре это соединение повторно не учитывается. Сваренные записи, ожидающие заявку/контроль, учитываются.
- Карточка, график, средняя выработка, разбивки и экспорт согласованы. Негодные остаются в диагностике и годности; под карточкой показано их количество, а в режиме WDI также объём. Количество включает негодные записи без WDI. WDI общей статистики отображается до двух знаков.
- Другие вкладки сохраняют прежние правила: например, полинейная сводка считает выполнение по датам сварки, а статистика сварщиков — фактически выполненные работы.
- В журнале, ЛНК и ПСТО сообщение об обновлениях остаётся слева. Справа сохраняются вычисленные итоги неизменённого выделения для показанной версии таблицы. Для нового выделения после устаревания версии показан прочерк до обновления: старые числа не выдаются за итоги другой области.
- Клик по числу копирует показанное значение без подписи и пробелов-разделителей; десятичная запятая сохраняется. Краткое подтверждение не перекрывает цифры и не сбрасывает выделение. Дата сварки остаётся обычным текстом.

Руководство приложения обновлено. В AGENTS.md зафиксировано согласованное распределение проверок: Chrome — основной браузер; WebKit — затронутые общие сценарии; подробные замеры установленного Safari — по конкретной необходимости.
