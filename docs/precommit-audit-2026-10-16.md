# Предкоммитная проверка — 16 октября 2026

**Предкоммитная проверка завершена; блокирующих дефектов в проверенном объёме не осталось.** По уточнению пользователя от 16.10 репетиция восстановления настоящего production-резерва и проверка того, как встанет обновление, выполняются отдельной локальной задачей **перед push**. Для текущего коммита эта репетиция не требуется.

Проверен весь незакоммиченный diff относительно `main`, HEAD `6c790058200ca0fcbe50bca098f57c1405804152`, включая новые untracked-модули: журнал AG Grid, документы, общие меню, формы, руководство и зависимости. Коммит, push и production-действия не выполнялись. Ветка/HEAD и пустой staged сохранены; на завершении 108 изменённых tracked-файлов и 44 untracked. Рабочая `welding_tracker` и пользовательские серверы 3000/4318 сохранены. Все прогоны использовали новую пустую локальную `welding_tracker_e2e` и временные шаблоны с проверкой владения; тестовая БД и аудитный контейнер удалены, порт 3100 освобождён.

## Исправления и приёмка

- По уточнению пользователя «Показать → текущую версию» берёт **видимые столбцы в экранном порядке, без группировки**. Состояние захватывается при нажатии, до запроса строк. Реальные предпросмотр, XLSX и печатный DOM проверены с сортировкой, скрытыми разделами, перегруппировкой, сохранённым видом и отказом localStorage. Группировка экрана относится к загруженным строкам; фильтрация/сортировка и вывод — к серверной выборке.
- Ссылки ПСТО открывают сохранённый документ и при отсутствии шаблона показывают объяснение. Портальный предпросмотр больше не открывает меню лежащего под ним стыка; вложенные окна сохраняют порядок Escape, фокус и горизонтальную прокрутку. Удалён старый оконный механизм и оставшийся без потребителей `serializeInlineScriptString`.
- Исправлено прежнее молчаливое блокирование действий, когда часть выбранных ID вышла за загруженную страницу. Полный выбор загружается одним явным запросом; отмена, повтор, устаревший ответ, смена выборки и открытие другого окна защищены. Удаление получает захваченные версии всех записей. Браузер подтвердил отмену и удаление ровно первоначальных 100 из 250 записей, включая 50 скрытых фильтром.
- Исправлено обрезание обычного контекстного меню длинными пояснениями: позиция теперь учитывает фактическую высоту. Исправлено обрезание кнопок назначения на узком экране. Оба дефекта воспроизведены до исправления; новые проверки сохраняют требования к границам окна, видимости кнопок и черновику.
- Устранено удержание снимков строк после удаления запросов из кэша. Реальная проверка сборщика мусора: до исправления оставались 24 из 24 снимков при пустом QueryCache, после — 0 из 24. Добавлены регрессии удаления/повторного создания запроса, устаревшего ответа и эквивалентных ключей; объединение запросов и ограниченное обновление сохранены.
- Закрыты найденные критические уязвимости TanStack Start минимальным согласованным обновлением зависимостей; проверена граница обработки входа серверной функции. Источник: [официальное уведомление TanStack](https://github.com/TanStack/router/security/advisories/GHSA-qx66-fv34-fjm8). Production audit — без уязвимостей; прежнее исключение для dev-only esbuild не расширялось.
- Руководство обновлено. Новых правил расчёта диспетчера, изменений схемы и миграций нет. ЛНК/ПСТО на AG Grid не переносились; исправление общего меню применяется к существующим таблицам.

Ожидания сверены с полными планами программы линий, системных правил, специалистов, обязательных реквизитов, печати и группировки документов и последними уточнениями, а не только с существующими тестами. Для недавних функций добавлены реальный Excel-импорт с одновременными ошибками и проверкой итоговой записи после частичного изменения, сохранность снимков специалистов в скачанных ВИК/ПСТО, работа с группами/видами и выбором за пределами страницы. Бизнес-основания: [план программы линий](line-program-plan-2026-09-25.md), [специалисты](specialists-plan-2026-10-12.md), [актуальная база журнала](ag-grid-welding-journal-2026-10-15.md), [постоянный объём аудита](precommit-audit-2026-10-01.md).

## Проверки и измерения

На окончательном коде прошли проверка типов приложения и E2E, production-сборка (148 серверных функций / 148 корректных RPC-ссылок), полный модульный набор — **578 файлов / 5960 проверок**, `git diff --check`. Метаданные Drizzle корректны; схема и миграции не менялись.

Полный браузерный прогон: **471 passed / 1 failed / 7 opt-in skipped** за 31,4 мин. Оставшийся сценарий прошёл бизнес-проверки, но считал ошибкой согласованное локальное отсутствие ключа AG Grid. При отдельном запуске на свежей БД обнаружилось также сравнение текста JSON вместо его структуры: первая инициализация индекса меняет только сериализацию, все значения шести документов совпали. После точной проверки известного баннера и полного структурного сравнения JSON повтор **всех трёх вариантов прошёл**. Итого подтверждены все 472 включённых сценария. Ещё три opt-in проверки — смешанная нагрузка и обе границы вывода — отдельно прошли на окончательной сборке. Повторы автоматическими retries не скрывались; критерии бизнес-логики сохранены.

Включены обычное удаление → восстановление тёзки → ремонт/вырез → будущее продолжение, серверные single/bulk/import-защиты и откаты, все четыре сценария ПСТО со специалистами и конфликтами, исторические/неполные записи, устаревшие клиенты, реальные формы/импорт/документы и сохранность черновиков. Ранние падения из-за старых HTML/оконных локаторов и гонок измерителей адаптированы к AG Grid и внутреннему предпросмотру; все прежние функциональные падения проверены повторно.

## Сохраняющиеся границы

- Отдельный этап перед push: восстановить настоящий production-резерв в изолированном локальном окружении и проверить применение обновления, сохранность данных/документов и восстановление после ошибки. Эта будущая задача не входит в предкоммитный аудит; её результат пока не подтверждён. Synthetic fixtures не заменяют реальный резерв.
- Новый AG Grid license key ожидается; по последнему решению это не блокирует локальный аудит и коммит. Подключение ключа к выпуску и любые production-действия требуют отдельного поручения.
- Часть single/bulk/import удалений и конкуренции проверяется публичными серверными API и PostgreSQL; не все комбинации проведены единым браузерным маршрутом до статистического XLSX. Проверка XLSX специалистов охватывает ВИК/ПСТО, не каждый метод после каждого переноса. Не утверждается полный перебор всех комбинаций через импорт/экспорт/печать.
- Однородный У19 остаётся отдельным нерешённым бизнес-вопросом; существующая проверка не объявляется новым согласованием. Полная системная AG-матрица, длительные сессии и фактические production-ресурсы не входят в выполненный умеренный обзор.
- Четыре специальных профиля не повторялись: отдельный холодный поиск отчёта на 200000, поиск программы линий на 200000, массовое перестроение всех системных документов и сравнительный `memory-working-set`. Для затронутых путей выполнены приведённые выше 200000-фикстуры, смешанная нагрузка, проверки числа запросов/объёма ответа и реальный GC-пробник; они не означают прохождение этих отдельных профилей.
- Статические кандидаты для будущего упрощения: открытая программа получает все строки линии (измерено 500 строк / около 936 КБ), ZIP держит буферы документов и выходной архив одновременно. Предварительное сужение линии или меньшие пакеты ZIP уменьшили бы расход ценой дополнительных действий; реальная частота таких объёмов неизвестна. Лимиты и функции без отдельного решения не менялись; защита истории, транзакций и конкуренции сохранена.
